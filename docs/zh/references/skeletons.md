# 类别骨架

骨架给出层的职责和时间关系；按游戏的风格删减。先选一个主形状，再只加它需要的辅助层。轻击可以非常简单；终结技可以有好几个阶段。
下面每个类别都有一个完整、经过独立评审的示例（`vfx examples show <name>` 打印它带绝对帧号和职责的层计划；
`vfx examples add <name>` 把它复制到项目中）：`hit`、`slash`、`charge`、`shield`、`heal`，以及飞行体 + 命中配对
`fire`、`ice`、`poison`、`dark`。

## 命中

参考：示例 `hit`（`VFX_Hit_Heavy`）。集中在接触点的短预兆，一个短暂的闪光，先出一个锯齿状爆点，然后是方向性的速度线和分档火花，最后以灰尘或少量烟收尾。
白闪让接触被感受到；主体传达力量。并不是每次命中都需要大环和黑烟。

| 职责 | 基元 | 替代方案 |
|---|---|---|
| 预兆 | 收缩的 `glow` | 几条向内的线 |
| 接触 | `flash` | 一个带轮廓的短促热形状 |
| 主体 | 手绘爆点 `sprite` 配 `POP` + `DISSOLVE`，`tilted_ring(..., tilt=(0,58,0))` | `shell` 空气泡 |
| 次级 | `spark_burst`（两到三档，一个喷射方向） | 带 `spray` 的 `radial_sparks` |
| 退场 | `smoke` 灰尘、`motes` 余烬 | 快速下落的灰尘；一次命中绝不持续数秒 |

如果峰值之后只剩细针，就延长或加强主体。如果看起来像烟花，先收窄发射方向和 `travel` 方向，而不是加粒子。预算 ≤ 60。

## 斩击

参考：示例 `slash`（`VFX_Slash_Fire`）。用 `swing()` 枢轴定义一个倾斜的挥砍平面，偏航约 ±30–40°，让弧读起来像一个劈过空间的椭圆；
`slash_set()` 把残影、主体和热边放在其中（三种宽度的 `slash_arc`：晚两帧的宽而暗的残影、饱和的主体、细的白色热边），
在刀刃后面加一道折射弧，以及一个保持几帧的手绘赛璐璐月牙。月牙是 `billboard='Fixed'`，位于刀刃自身的平面中（相同的 lean），
按纹理实测的弧顶凸出（`SLASH02_BULGE`）旋转，因此它随挥砍倾斜，而不是面向镜头。火花沿弧错开出现。火的退场是剥落的火焰和上升的余烬，物理是短促的金属火花，冰是停顿之后碎裂。
换元素改变的是运动和材质，而不只是颜色。

保留层与层之间弧内的负空间。目标胸口只是放置锚点：弧的视觉中点还取决于纹理的弧顶凸出、旋转和枢轴 —— 用 `vfx texture-info` 实测。
如果尾段仍是一整道月牙，先修扫掠和侵蚀，再考虑加烟化残影。

## 爆炸

参考：示例 `VFX_Fire_Explosion`。Gather 和 Inward fuse 在目标处收紧，短促的 Detonation flash 释放，Fireball 和上升的
Mushroom 接替，方向性的碎片和火花传递冲击，Smoke billow、灰尘和地面痕迹给出重量。

闪光之后火焰必须保持饱和的体积 —— 不能只是一个扩张的环或很多小亮点。次级运动沿射击方向、地面或向上组织；不要所有层都做同样的球形运动。
烟画在火的后面，接替冷却后的形状；如果烟盖住了中心，先检查顺序和密度。地面痕迹说明它落在哪里，上升的体积说明它喷发了；
更大的满屏光晕无法替代其中任何一个。看 f18–42 的交接和 f54–66 的烟，而不只是峰值。

## 飞行体

参考：配对 `fire`、`ice`、`poison` 和 `dark`（`VFX_Projectile_Fire`、`VFX_Projectile_Ice`、`VFX_Projectile_Poison`、
`VFX_Projectile_Dark`）。头部层（Fireball、Hot core）跟随 handle；
Comet tail 给头部方向感；Flame trail、Smoke trail 和 Embers 使用 `inherit=TRAIL`，留在路径上。宽拖尾、细热线和短促的脱落粒子
需要不同的寿命；头部和路径都必须可读。

检查发射、飞行中段、到达、到达之后和清空。飞行时间固定时，拖尾密度由发射间隔和粒子寿命共同决定。改变头部的继承方式会改变空间关系 ——
不要用拉长拖尾来掩盖僵硬的管子。命中是配对效果：分别复查飞行体连拍和命中连拍，在 Lab 中看完整的交锋。预算 ≤ 100。

## 蓄力与释放

参考：示例 `charge`（`VFX_Magic_Charge`）：约一秒的向内蓄积（f0–64），一次释放 f64–70，释放火花持续到约 f86。
`travel` 为负的 `motes` 和 `radial_sparks` 向内汇聚，两个位于不同倾斜平面的 `orbit_band` 环建立体积，核心和光环逐渐积累，
释放闪光、`shell` 和火花给出一次清晰的释放。镜头和舞台反馈可以加强释放，但汇聚本身必须可读。

只在 Z 轴旋转、内部没有流动的环会变成一个旋转图标；用 UV 流动（`alpha_scroll`）、倾斜平面和向内的 travel。
如果释放很大而预兆很弱，先建立一条可见的汇聚路径，而不是把所有亮度都调高。

## 护盾与持续状态

参考：示例 `shield`（`VFX_Shield_Dome`）以及 [cases](cases.md) 中的护盾案例。一个短促的升起闪光，一个 `mesh` 球体 `shell` 加边缘提供持续体积，表面流动、扫描带和闪光让保持段保持生动。结束时整个壳交接给带真实间隙的
`shell_fragments`；碎片运动和颜色衰减构成退场。

稳定不等于每帧闪烁，也不等于一个整球一下子关掉。先检查壳内的角色是否可读，再看表面流动和退场。六片球面碎片是这里已验证的方案；
其他材质能否真正溶解，必须单独测试。

## 治疗与增益

参考：示例 `heal`（`VFX_Heal`）。地面 `decal` 法阵说明归属，`column` 建立缓慢上升的体积，上升的环、符号和生命 `motes` 承载含义，光晕和闪烁星点收尾。
不要把治疗做成带剧烈白闪和爆裂碎片的攻击。它可以柔和或脉动，但必须保持轮廓，并在标准镜头中可见。
白色峰值不是这一类别的合格标准；使用评分表中按用途的例外。

## 使用示例代码

`vfx examples show <name|ID>` 打印带绝对帧号和职责的完整层计划；`vfx examples add <name>` 把源码、简报和手绘纹理复制到项目中。
想保留示例作为基线时，用新 ID 改编一份副本，而不是直接修改示例。示例的历史分数描述的是本技能自己的渲染，不是你的构建：
任何修改之后都要重新构建、复查并再次取得独立评分。有两个示例被判为 `iterate`（见 `vfx examples`，`historical_review.worst`）；
它们仍能教会各自的模式，而它们最弱的地方正好是不错的第一个练习。
