# 体积与遮挡

先决定主体的体积：冰刺是晶体，光柱是程序化圆柱，冲击波是倾斜的环或薄壳，吸积盘是远半环 + 核心 + 近半环。
面向镜头的 sprite 留给闪光、烟雾和本来就应该朝向镜头的形状。在标准镜头和可选的近景（`vfx review --view close`）中检查，
但效果库的基线仍然是标准的对战站位。

本机实测：球体的 depth 与圆柱的工作方式不同（球体用 scale 控制尺寸）；Cone 尖端的方向不能靠猜（晶体用带端部半径的 Cylinder）；
Model 层不能依赖 ZWrite，因此遮挡取决于列表顺序。Fresnel 的 `begin`/`end` 和 `pow` 的行为如 [引擎约定](engine-conventions.md)
中所记录，而不是像它们的名字暗示的那样。

大型的壳和柱不能变成半透明的实心穹顶。先检查轮廓、内部透明度和角色可见性，再看亮度；满屏光晕掩盖不了形状问题。
暗核必须在默认舞台上可读，也要检查亮背景（`--bright`）。

优先使用现有的 Ring、Model、UV 滚动和溶解功能。自定义网格是之后的资产路径：先证明没有任何基元能表达这个形状，
再验证导出、UV 以及资源能随包一起带走。绝不为了绕开未经验证的假设去修改官方渲染器。

## 从标准镜头出发选择体积

| 主形状 | 这里可用的构造 | 要检查的空间关系 |
|---|---|---|
| 斩击 | 带倾斜 Ring 的枢轴，或固定平面的弧 | 弧穿过动作点，内侧留有空间 |
| 爆炸 | `billow`、上升的主体、倾斜的波和地面物质 | 有落点和高度；近层和远层分开 |
| 暗核 | 按顺序：远半环、核心、近半环 | 前半部分从核心前面经过，后半部分被核心挡住 |
| 冰晶 | 带尖端的六棱柱、碎片和冷雾 | 尖端方向和棱面受光不同；碎裂不只是亮点 |
| 持续的壳 | fresnel 轮廓、表面运动、碎片退场 | 壳内的角色、壳表面和背景都可读 |
| 光柱 | 圆柱、静态 alpha 渐变和滚动条纹 | 顶部和底部自然淡出；主体上没有 UV 接缝 |

在标准镜头里，贴地的低矮环可能只读成一条细线，精致的近景细节在战斗距离上可能消失。先建立横向或向上的体积，再加更多表面纹理。
近景帮助发现问题；它不能代替标准镜头来判断尺度。

当层前后重叠时，先安排绘制顺序，再在图像中验证。画在所有碎片前面的完整壳轮廓会把本该出现的间隙重新封上；
画在火焰前面的暗烟会挡住本该留下的饱和主体。几何正确，也可能因为顺序而读错。
