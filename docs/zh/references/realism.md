# 照片级的爆炸、火焰和烟

当简报要求写实外观（电影、实拍参考、照片级写实的游戏）而不是默认的风格化外观时使用本文。制作规则依然适用 —— 时间结构、
明度分层、形状变化 —— 但颜色、亮度和纹理来自照片。

## 来自照片的颜色和亮度

燃料和弹药爆炸的日光照片与高速影片在下面这些数值上一致（sRGB，未经 Lab 泛光）。它们就是 `VFX_Kaiju_Explosion` 的调色板：

| 职责 | RGB | 说明 |
|---|---|---|
| 接触核心 | 255, 244, 214 | 淡黄白，**不是**纯白；一次短促的尖峰，约 8 个 Lab 帧内消失 |
| 火焰主体 | 255, 168, 72 | 橙色；接触之后，主体是最亮的部分 |
| 冷却边缘 | 214, 84, 28 | 火焰与烟灰相接处的深红橙 |
| 最后的余光 | 120, 40, 18 → 60, 20, 10 | 烟里暗红的余火团，然后熄灭 |
| 烟灰 | 38, 32, 29 | 偏暖的近黑色，不透明：火在它前面燃烧 |
| 烟柱 | 92, 84, 78 | 棕灰色；顶部受阳光照射处较亮，底部较暗 |
| 尘埃裙边 | 150, 136, 118 | 地面的颜色，比烟浅 |
| 蒸汽 | 205, 215, 225 | 近白色，稀薄，上升很快并消失 |

- **火焰中避免粉色和品红。** 饱和的红粉色（R 和 B 都高）一眼就会被看成游戏特效。
- **火焰不会长时间保持白色。** 照片中白热的画面只有一两帧；之后最亮的像素是黄橙色。在 Lab 的泛光下，在一段长寿命中
  10 % 都停留在近白的 ramp，读起来是一次过曝的闪光（一次独立评审恰好指出了这一点）；在约 5 % 处就转为橙色。
- **烟比火存活得久得多**，而且移动缓慢：真实的爆炸中，火球大约一秒就消失，烟柱则持续攀升许多秒。保持它的浓度
  （colour_end 的 alpha 大于零），在它仍然明显变稀薄时结束效果，而不是等它完全消失之后。
- **烟从上方受光。** 照片级的烟雾序列图顶部亮、底部暗；把滚转保持在小范围（±12°），让光一直在顶部，并用
  `spawn rotate=False` 发射，使 `velocity` 朝世界上方。
- Emissive：加色火焰 1.3–1.8 就够了；更亮的值会把主体推过泛光阈值，变成白色。卖点是明度结构（淡色核心、橙色主体、
  暗色烟灰），而不是原始强度。

## 纹理

手绘的风格化烟团放在照片级写实的世界里看起来像卡通。本技能随附三张照片级序列帧（4×4，1024²，由图像模型生成并处理；
提示词在 `assets/examples/texture_prompts.json` 中）：

| 纹理 | 用途 | 混合 |
|---|---|---|
| `T_FireballSheet01` | 火球：alpha = 亮度，所以炽热的团块发光，烟灰透明 | Add，配 `ramp` |
| `T_FireballSootSheet01` | 同一个火球的不透明主体（着色的灰色，完整剪影） | Blend，排在火焰**之前** |
| `T_SmokeSheet02` | 照片级的翻滚烟柱，顶部受光 | Blend，用烟的颜色着色 |

`smoke()` 会把任何 `T_*Sheet*` 纹理当作 4×4 序列帧播放。对于必须一直浓到最后的烟柱，放慢序列帧
（`flipbook=dict(x=4, y=4, frame_length=8, loop='Once')`），让它在图集最后几格几乎空白的帧之前停下。

## 烟和火与地面相接

穿过地面或水面的 sprite 会留下一条硬的水平线。给地面的烟、尘和蒸汽一个 `soft` 距离（世界单位，烟团尺寸的三分之一到二分之一）
—— 已在 Forward+ 中验证，见 [引擎约定](engine-conventions.md#渲染hdr-与-lab)。

## 照片级爆炸的层计划

从后到前：热浪扭曲 → 烟柱（soft，慢速序列帧）→ 烟灰主体（Blend）→ 火球（Add，照片级 ramp）→ 从火球甩出的火舌 →
接触闪光和短暂的光晕 → 带 soft 尘埃裙边向外滚动的地面枢轴 → 地面冲击环和折射 → 分档的火花 → 会落地的暗色碎块。
`vfx examples show VFX_Kaiju_Explosion` 会打印时间线。
