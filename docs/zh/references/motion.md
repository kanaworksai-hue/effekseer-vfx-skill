# 运动与路径

飞行体规划三种职责：跟随 handle 的**头部**、留在世界空间中的**拖尾**，以及从路径上掉落的**脱落粒子**。用 `sustain()` 发射，
用 `inherit=TRAIL` 保留拖尾；到达时游戏调用 `stop_root()`，它们会自然消散。头部需要清晰的轮廓；拖尾在长度和明暗上要有区别；
发射瞬间的一条速度线或一个短环能帮助观众读出速度。

斩击用真实的平面和扫掠（`swing()` + `slash_arc`）展示路径，然后沿弧错开次级发射。次级粒子用缓动的 `travel` 从快到慢；
Drag 不会衰减 PVA 速度（见 [引擎约定](engine-conventions.md)）。写 `travel` 之前先算清旋转后的局部坐标轴：球形发射和圆形发射的径向轴不同。

分开诊断体积和路径：细拖尾可以没问题，但头部不能变成没有体积的点。飞行体自己的连拍在到达时结束，不包含命中；
Lab 的正常播放会展示完整的配对。

运动不只是缩放。用扫掠、侵蚀、UV 流动、旋转枢轴和变形改变主形状；按元素方向组织碎片、烟雾和微粒：冰先停顿再碎裂，暗向内吸，
火上升，毒缓慢下沉 —— 每一种都要有连续帧支撑。

运行时提供直线和抛物线（`arc`）路径。曲线路径、齐射或持续光束需要先写简报并扩展运行时；绝不要告诉用户本技能没有的工具或 API 存在。

## 把速度放进形状和节奏

| 可见问题 | 先检查 | 先改什么 |
|---|---|---|
| 飞行体看起来像漂浮的球 | 发射时有没有方向变化和速度载体？ | 短的后掠风线、方向性火花或长度不同的尾巴 |
| 拖尾看起来像塑料管 | 是否宽度均匀、颜色平、所有层寿命相同？ | 给纹理留负空间；把短的热尾和长的柔和尾分开 |
| 火花匀速漂浮 | `travel` 是否先快后慢？ | EaseOut，然后由重力或轻微运动接手 |
| 斩击像贴在镜头前的贴纸 | 有没有真实的倾斜平面、扫掠和跟随它的发射？ | 先修平面和扫掠，再沿弧错开细节 |
| 碎片像规则的烟花 | 尺寸相同、出生帧相同、球形对称？ | 分档尺寸和节奏；沿动作方向组织主运动 |

速度载体的存在是为了让观众读出方向；它不必是一组新粒子。如果拖尾或形状已经起到这个作用，就保持简单。元素可以停顿，
但停顿必须引出一个明确的动作：冰晶停止生长然后碎裂；暗能量汇聚然后释放。

相同的角度范围并不能让亮粒子和暗粒子对齐。几何配对使用固定参数；用 [layering](layering.md) 中的步骤诊断运动错位。
烟化残影可以刻意按不同的节奏运动，但要在简报中写明。
