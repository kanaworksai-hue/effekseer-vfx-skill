# VFX 制作规则

所有配方都建立在这些规则之上。编写或修改效果之前先读它们，并一起读 [layering](layering.md)、[timing](timing.md) 和
[skeletons](skeletons.md)。这里的制作起点可以按用户的风格调整；[engine-conventions](engine-conventions.md) 中实测的引擎行为则不能改。

目录：1. 为什么"贴纸感"的效果不行 · 2. 时间结构 · 3. 元素之间的差别 · 4. 飞行体 · 5. 不规则与多职责的效果 · 6. 预算

## 1. 为什么"贴纸感"的效果不行

静态 billboard 换个颜色、放大再淡出，看起来就是一张贴纸。让效果读起来像效果的是下面五件事，缺任何一件质量都会明显下降：

1. **时间结构**：预兆 → 接触闪光 → 主体 → 次级运动 → 消散。接触只占 2–5 帧；消散占大半时长。
2. **亮度分层**：白热核心、饱和主体和更深的外沿或残留 —— 而不是整片同一种颜色。
3. **形状变化**：主体会侵蚀（alpha cutoff 溶解）、抖动（UV 扰动）或扫掠展开；只靠缩放和透明度不够。
4. **速度有变化**：粒子先爆出，再悬停下坠（缓动位移），绝不匀速排成一条线。
5. **画面反馈**：命中时的泛光、环境闪光和镜头抖动。Lab 根据 manifest 的 `impact`、`light` 和 `peak` 生成它们；
   关掉它们（`--profile bare`）时效果也必须成立。

## 2. 时间结构

| 阶段 | 帧数 (60 FPS) | 做法 |
|---|---|---|
| 预兆 | 2–14 | 收缩的小光晕、地面警示圈、细引导线。打击越重，预兆越长 |
| 接触 | 2–5 | `flash` 白色星芒，尺寸是主体的 1.5–2 倍，随即消失 |
| 主体 | 8–20 | 手绘形状用 `POP` 弹出，再用 `DISSOLVE` 侵蚀；`shock_ring` 外扩 |
| 次级 | 10–40 | `radial_sparks`、`motes`、碎片、火舌，带重力 / 上升 / 湍流 |
| 消散 | 20–60 | 烟、余烬和地面裂纹的余光慢慢冷却 |

治疗、护盾和增益去掉接触帧，改用慢速淡入、上升运动和轻微过冲。蓄力把结构倒过来：长时间向内积蓄，释放时一次闪光。

## 3. 元素之间的差别

只换色不是新元素。同一类别的两个元素至少要在**形状、运动、节奏、材质、次级运动**中的三项上不同（不满足时 `vfx lint` 会警告）：

| 元素 | 形状 | 运动 | 节奏 | 次级 |
|---|---|---|---|---|
| 物理 | 锯齿状爆点、速度线 | 径向爆开，然后下坠 | 最短，0.3–0.65 s | 火花、灰尘 |
| 火 | 翻滚的火球、火舌 | 上升、UV 扰动 | 中等，拖尾长 | 上飘的余烬、黑烟 |
| 冰 | 棱柱、碎片 | 过冲、静止停顿，然后碎裂 | 有停顿 | 受重力下落的碎片、下沉的冷雾 |
| 雷 | 锯齿折线 | 不移动；逐帧切换或镜像的闪击 | 主击、回击、余闪落在不同帧 | 地面裂纹、爬行电弧 |
| 暗 | 漩涡、黑色核心 | 向内吸入 | 长时间吸入 + 一次释放 | alpha 混合的黑色主体、内吸微粒 |
| 圣 | 法阵、光柱 | 垂直下落或上升 | 缓入，持续 | 上升的光环、闪烁星点 |
| 毒 | 团雾、气泡 | 缓慢漂移、下沉的雾 | 最慢，约 2 s | 上浮的气泡、孢子 |

## 4. 飞行体（category `projectile`）

飞行体没有接触帧。它的命中是一个单独的效果，由 `Vfx.launch` 的 `arrived` 信号触发。飞行体配方声明 `flight`
（参考飞行的秒数），抛射弧线还要声明 `arc`（飞行中点的抬升高度，单位米）。命中效果用
`delivery=dict(kind='projectile', projectile='VFX_...')` 反向指向它。

- **头部**层跟随 handle（默认继承）。**拖尾**层使用 `inherit=TRAIL`（位置、旋转和缩放都是 `WhenCreating`），
  留在出生的位置，因此路径会自己画出来。两者都用 `sustain(layer, interval)`（`infinite`）发射；游戏在到达时调用
  `stop_root()`，之后只剩拖尾的消散。lint 按在 `flight` 时释放来计算寿命；预算按 life/interval 计算同时存活的实例数。
- 元素之间在飞行节奏和次级运动上也要有差别：火会闪动、上升并转成黑烟；冰又快又直，脱落的碎片下落，留下下沉的冷雾；
  暗是 alpha 黑色核心，把针状粒子向内拖拽，尾迹收缩；毒走抛物线，滴落、冒泡，留下悬停的毒气。
- 复查连拍让飞行体从施法者飞向目标，在到达时结束。它的质心和半径跟随飞行路径，而不是元素本身的运动，
  所以飞行体不检查 `sinks` 和 `expands while charging` 这两个 flag。

## 5. 不规则与多职责的效果

让远程和命中效果读起来像专业作品的技巧（随附的示例配对都用到了）：

1. **用残缺的弧，不用完整的环。** 主体由几条不完整的笔触组成，每条扫过 60–200°，半径、倾角和宽度各不相同，彼此交叉。
   用 `wisps`（带常驻侵蚀的手绘丝状笔触），不要用干净的 `shock_ring`、`shell` 或圆形 billboard 做主形状。
2. **多个职责，各有分工。** 复杂的远程技能可能同时有弧、白热核心、暗核、两档火花、微粒、灰尘、碎块和地面痕迹。
   说明每个职责的用途；不要把层数当作合格线。轻击和简单技能需要的少得多。
3. **暗色元素必须看得见。** 在暗色舞台上，灰色烟雾和碎块的数值大约要在 90–150；`(40,10,70)` 这样的颜色画了等于没画。
4. **有用途的小面积强调色**：暗系的橙色下沿、冰的棱镜边、毒下方的暗核。5–10 % 的面积只是初次尝试的起点；
   先在简报里确定主色和强调色的职责。
5. **光衰减成烟。** `decay()` 给一条加色笔触配一个 alpha 混合的灰色副本，晚几帧开始，寿命是 1.6–2.2 倍：
   光先熄灭，形状以烟的形式留下。
6. **一根长细线。** 释放时用一条 `slice_line` 横穿半个画面，长宽比大于 40:1，持续 8–15 帧。
7. **方向性。** 碎块、火花和液滴沿射击方向（+X）略偏上喷出（`spray`、`debris`），而不是对称的球形。
8. **地面反馈。** 外滚的灰尘、落地弹跳的碎块、焦痕、裂纹、液池和法阵把效果钉在地面上。
9. **冲击帧。** 近黑的全屏卡和白色闪光放在**同一帧**（黑卡排在闪光之前）。把黑卡提前，暗系的
   "expands while charging" 检查就会把它读成扩张。

## 6. 预算

粒子实例（`particle_budget`，父 × 子）：普通命中 ≤ 60，飞行体 ≤ 100，元素技能 ≤ 150，Boss 技能 ≤ 250。
同时存活的满屏加色层最多三个。纹理 128–256 px；手绘主形状和法阵 512 px；4×4 序列帧图集 1024 px。
