# 明暗、颜色与图层配对

先规划观众在标准镜头中能读出的三样东西：一个短促的亮点、一个有形状的主体，以及一个能衬出主体的暗面或物质。
每增加一层都要说出它解决的是哪个可见问题；层数不是质量指标。

## 先定调色板职责

| 职责 | 应该看到什么 | 第一种调法 |
|---|---|---|
| core | 一小块最热的区域或一条细热边，接触时清晰 | 先控制尺寸和时长，再考虑加 emissive |
| body | 能认出元素和动作的饱和轮廓 | 白闪退出后保留形体；冷却它的颜色而不是把它去掉 |
| dark | 衬底、凹面、裂口或真实的阴影 | 用 Blend，并检查亮背景和暗背景；黑色 Add 做不了这件事 |
| matter | 烟、灰尘、碎片、液滴 —— 重量 | 降低饱和度，保留内部明暗和可见的退场 |
| accent | 一小块第二色线索 | 给它一个位置或阶段，再检查它没有抢走主色 |

主色可以是单一色，也可以是一组相邻色。第二种颜色需要有用途（冰的棱镜边、毒的暗核）；绝不每层选一种颜色，
也不强制使用互补色。火旁边的烟可以先经过暖色再变灰，但不要把所有烟都重新涂成饱和的橙色。

先在灰度下看明暗，再看色相。如果核心、主体和背景都接近白色，加橙色粒子也恢复不了结构。先找出是哪一层先把画面推白：
接触、某个光晕、主体，还是多个 Add 层重叠。

## 三种副本承担不同的工作

| 做法 | 几何与时间关系 | 用途 | 典型错误 |
|---|---|---|---|
| 暗衬底（`shadow()`） | 独立的形状，可以略大，与主体大致同阶段 | 衬出亮色；提高亮背景下的可读性 | 一团黑吞没主体（看成黑洞）；在暗舞台上看不见 |
| 明度配对（`contrast_pair()`） | 完全相同的轮廓、固定角度、相同的运动和出生时刻 | 在一个形状内部增加明暗结构 | 两个随机轮廓漂开，变成两条无关的笔触 |
| 烟化残影（`decay()`） | 可以延迟、更慢、更长，颜色和混合方式不同 | 光熄灭后留下物质 | 一道暗色刀弧长时间悬挂，看起来像一块脏拖影 |

`decay()` 不是几何完全一致的明度配对。

确定性的配对要固定 `count=1`、life、size、rotation、position、spin、travel 和 flipbook 起始帧。不同的粒子节点各自取随机值：
相同的范围和同一个全局 seed **不能**保证取到相同的角度。需要很多方向时，由外层选定一个固定角度，两个节点都使用这个固定值；
绝不要分别给每层 `[0,360]`。

严格的配对保持相同的寿命和归一化曲线。延长寿命也会移动到达生命周期 50 % 的实际帧，于是缩放和扫掠就会错开。
想让暗层更晚退出，要显式重算它的曲线，或者把它做成独立的残影，不再称它为匹配的轮廓。

本机实测：后面的层画在前面，Model 的 ZWrite 不能提供这里的遮挡 —— 用绘制顺序。先画 Blend 暗副本、再画 Add 亮主体是一个起点；
画在前面的暗色切口和画在后面的暗色衬底是两种不同的设计，要看渲染结果决定。

```python
from vfxkit.primitives import *

body = sprite('Matched burst', 'T_Explosion01', (255, 120, 30, 255),
    life=16, delay=3, size=2.0, rotation=[0, 0, 30],
    size_curve=[[0, .8], [30, 1], [100, 1.1]],
    color_curve=ramp((0, (255, 120, 30, 255)), (100, (180, 35, 10, 0)))['color_curve'],
    alpha_texture='T_NoiseTile01', cutoff=[[0, 0], [100, .8]],
    fade_in=0, fade_out=4, emissive=1.2)
layers = contrast_pair(body)   # [Blend dark underlay, the bright body]; splice into effect(..., [*layers, ...])
```

两层共享几何和时钟，只在颜色和材质上不同。alpha、混合和 cutoff 仍会改变实际边缘，所以要检查渲染；不保证像素级重合。
30° 是演示用的角度，不是这张纹理的朝向：运行 `vfx texture-info`，按实测角度确定动作方向。这个辅助函数只处理一个 Sprite；
Ring 和 Model 的配对要显式设计。

## 尺寸与寿命的起点

以主体的**可见宽度 B** 和**寿命 L** 为基准，而不是 sprite 卡片的尺寸：只含一根细线的纹理，与同样大小的满卡分量并不相同。

| 层 | 起点 | 如何确认 |
|---|---|---|
| 热核心 | 约 0.2–0.5 B 宽，或主体的一条细边 | 峰值时能找到核心，之后仍能找到主体 |
| 暗配对 | 与主体同尺寸、同寿命 | 如果尺寸改变，重新决定它是切口还是衬底 |
| 独立衬底 | 略大，约 1.1–1.4 B | 主体外面没有形成一圈干净的黑色圆 |
| 暗残影 | 约 1.1–1.2 L | 亮层消失后，留下一小段刻意的层 |
| 烟化残影 | `decay()` 给出的更长寿命 | 退场时仍在变形；不是一道静止的暗弧 |

这些是调试起点，不是统计结论，也不是 lint 规则。斩击和持续光柱可以用细长的热边；治疗和护盾不需要攻击式的白闪。
曲线匹配、负空间和标准镜头比这些比例更重要。

## 白团与黑团的修复顺序

主体被白色填满时：逐个关掉光晕、接触和重复的 Add 层，定位原因；然后缩短接触；然后削减主体持续时间过长的高亮段；
最后再加暗色。不要同时改纹理、曲线、烟雾和镜头抖动 —— 那样你不会知道是哪一项起了作用。

暗层读起来像一条独立的黑色笔触时：先检查角度和尺寸是否对齐，然后检查出生时刻和寿命，最后才是灰度值。
不要用降低不透明度来掩盖错误的几何。如果在亮背景上成立而在默认舞台上不成立，给物质层一个合适的灰色或局部受光的颜色，
同时保持 dark 和 matter 两种职责的区分。

完成的一轮可以用一句话加上你看过的帧号说出改善点，例如"f12 之后白闪已经消失，橙红色火球保持住了轮廓"。
参见 [火焰爆炸案例](cases.md#火焰爆炸一直不退的白色接触)。
