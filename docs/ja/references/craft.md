# VFX クラフトルール

すべてのレシピの土台となるルールです。エフェクトを書く・変更する前に、[layering](layering.md)、[timing](timing.md)、[skeletons](skeletons.md) と一緒に読んでください。ここにあるクラフト上の出発点はユーザーのスタイルに合わせて調整して構いませんが、[engine-conventions](engine-conventions.md) にある実測済みのエンジン挙動は変えてはいけません。

目次：1. 「ステッカー」エフェクトが失敗する理由 · 2. 時間構造 · 3. 属性の違い · 4. 飛翔体 ·
5. 不規則で複数の役割を持つエフェクト · 6. 予算

## 1. 「ステッカー」エフェクトが失敗する理由

色を変え、拡大し、フェードアウトするだけの静的なビルボードは、ステッカーに見えます。エフェクトをエフェクトらしく見せる要素は 5 つあり、どれか一つが欠けても品質は目に見えて落ちます。

1. **時間構造**：予備動作 → 接触フラッシュ → 本体 → 二次モーション → 消散。接触は 2〜5 フレーム、消散は尺の大半を占めます。
2. **明度の階層**：白熱コア、高彩度の本体、暗い外縁または残滓 — 平坦な単色ではありません。
3. **形状の変化**：本体が侵食される（アルファカットオフによるディゾルブ）、揺らぐ（UV ディストーション）、スイープして開く。スケールと不透明度だけでは足りません。
4. **速度の変化**：パーティクルは弾け出てから、宙に留まり垂れ下がります（イージングした移動）。一直線に等速で動かしてはいけません。
5. **画面へのフィードバック**：着弾時のブルーム、環境フラッシュ、カメラキック。Lab はこれらをマニフェストの `impact`、`light`、`peak` から導き出します。それらをオフにしても（`--profile bare`）エフェクトは成立していなければなりません。

## 2. 時間構造

| フェーズ | フレーム数（60 FPS） | 方法 |
|---|---|---|
| 予備動作 | 2–14 | 縮んでいく小さなグロー、地面の警告リング、細いガイドライン。重いヒットほど予備動作を長く |
| 接触 | 2–5 | `flash` の白い星形。本体サイズの 1.5〜2 倍で、すぐに消える |
| 本体 | 8–20 | ペイント系の形状が `POP` で現れ、`DISSOLVE` で侵食される。`shock_ring` が広がる |
| 二次モーション | 10–40 | `radial_sparks`、`motes`、破片、炎の舌。重力・上昇・乱流を付ける |
| 消散 | 20–60 | 煙、残り火、地面の亀裂の光がゆっくり冷めていく |

ヒール、シールド、バフは接触フレームを持たず、代わりにゆっくりしたフェードイン、上昇する動き、わずかなオーバーシュートを使います。
チャージは構造が逆になります：長い内向きの溜めの後、解放の瞬間に一度だけフラッシュします。

## 3. 属性の違い

色替えは新しい属性ではありません。同じカテゴリの 2 つの属性は、
**形状、モーション、リズム、マテリアル、二次モーション** のうち少なくとも 3 つで違っていなければなりません（違わない場合は `vfx lint` が警告します）。

| 属性 | 形状 | モーション | リズム | 二次モーション |
|---|---|---|---|---|
| 物理 | ギザギザのバースト、集中線 | 放射状に弾けてから垂れる | 最も短い、0.3–0.65 s | 火花、土埃 |
| 炎 | もくもくと膨らむ火球、炎の舌 | 上昇、UV ディストーション | 中程度、長いテール | 立ち昇る残り火、黒い煙 |
| 氷 | 角柱、破片 | オーバーシュートして静止し、その後砕ける | 「溜め」がある | 重力で落ちる破片、沈んでいく冷気 |
| 雷 | ギザギザの折れ線 | 移動しない。フレームごとに差し替えたり反転したりする落雷 | 主落雷、リターンストローク、残りの明滅が別々のフレームに | 地面の亀裂、這い回るアーク |
| 闇 | 渦、黒いコア | 内側へ引き込む | 長い引き込みと一度の解放 | アルファブレンドの黒い本体、内向きのモート |
| 聖 | 紋章、光の柱 | 垂直に降りる、または昇る | イーズインして持続 | 立ち昇るハロー、きらめき |
| 毒 | 雲、泡 | ゆっくり漂う、沈む霧 | 最も遅い、約 2 s | 立ち昇る泡、胞子 |

## 4. 飛翔体（カテゴリ `projectile`）

飛翔体には接触フレームがありません。着弾は別のエフェクトで、`Vfx.launch` の `arrived` シグナルで発火します。
飛翔体のレシピは `flight`（基準となる飛行の秒数）を宣言し、山なりに飛ばす場合は `arc`（飛行中間点での持ち上がりをメートルで）も宣言します。着弾側は `delivery=dict(kind='projectile', projectile='VFX_...')` で飛翔体を参照し返します。

- **ヘッド** レイヤーはハンドルに追従します（既定の継承）。**トレイル** レイヤーは `inherit=TRAIL`（位置・回転・スケールを `WhenCreating`）を使い、生まれた場所に留まるので、軌跡が自然に描かれます。どちらも `sustain(layer, interval)`（`infinite`）で放出し、ゲームは到達時に `stop_root()` を呼びます。その後に残るのはトレイルの消散だけです。lint はライフタイムを `flight` の時点で解放されたものとして計算し、予算は同時に生存する life/interval のインスタンス数を数えます。
- 属性ごとに飛行のリズムと二次モーションにも違いを付けます：炎は揺らめき、上昇し、黒い煙に変わる。氷は速くまっすぐ飛び、落下する破片を振りまき、沈む霧を残す。闇はアルファブレンドの黒いコアで、縮んでいく航跡とともに針を内側へ引きずる。毒は弧を描いて飛び、滴り、泡立ち、漂う毒煙を残す。
- レビューのストリップでは、飛翔体は術者からターゲットへ飛び、到達で終わります。重心と半径は属性の動きではなく飛行経路に従うため、飛翔体では `sinks` と `expands while charging` のフラグはチェックされません。

## 5. 不規則で複数の役割を持つエフェクト

遠距離エフェクトと着弾エフェクトをプロの仕事に見せる技法です（同梱のサンプルペアはこれらを使っています）。

1. **完全なリングではなく、途切れた弧。** 本体を、それぞれ 60–200° をスイープし、半径・傾き・幅の異なる不完全なストロークを複数交差させて組み立てます。メインの形状にはきれいな `shock_ring`、`shell`、丸いビルボードではなく、`wisps`（常時侵食のかかったペイント系ウィスプの筋）を使います。
2. **複数の役割、それぞれに仕事を。** 複雑な遠距離スキルでは、弧、白熱コア、黒いコア、2 段階の火花、モート、土埃、破片、地面の痕跡を組み合わせることがあります。各役割の目的を明示し、レイヤー数を合格の目安として扱ってはいけません。軽いヒットや単純なスキルでは、はるかに少なくて済みます。
3. **暗い属性は見えなければならない。** 暗いステージでは、グレーの煙や破片の明度は約 90–150 必要です。`(40,10,70)` のような色は描いていないのと同じです。
4. **目的を持った小さなアクセント**：闇にはオレンジの下面、氷にはプリズムの縁取り、毒には下に暗いコア。面積の 5〜10 % は最初の試し値にすぎません。メインとアクセントの役割は、先にブリーフで決めておきます。
5. **グローは煙へと減衰する。** `decay()` は加算のストロークに、数フレーム遅れて始まり 1.6〜2.2 倍長く生きるアルファブレンドのグレーのコピーを付けます：光が先に消え、形は煙として残ります。
6. **長く細い一本線。** 解放の瞬間に、画面の半分を横切る縦横比 40:1 以上の `slice_line` を 8〜15 フレーム。
7. **方向性。** 破片、火花、飛沫は対称な球状ではなく、射線（+X）に沿ってやや上向きに飛ばします（`spray`、`debris`）。
8. **地面へのフィードバック。** 転がる土埃、着地して跳ねる破片、焦げ跡、亀裂、水たまり、紋章がエフェクトを床に繋ぎ止めます。
9. **インパクトフレーム。** ほぼ黒の全画面カードと白いフラッシュは **同じフレーム** に置きます（黒いカードをフラッシュより前にリストする）。黒いカードを早く置くと、闇の「expands while charging」チェックがそれを膨張と読んでしまいます。

## 6. 予算

パーティクルのインスタンス数（`particle_budget`、親 × 子）：通常のヒット ≤ 60、飛翔体 ≤ 100、属性スキル ≤ 150、
ボススキル ≤ 250。画面サイズの加算レイヤーが同時に生存するのは最大 3 つまで。テクスチャは 128–256 px、ペイント系のメイン形状と
紋章は 512 px、4×4 のフリップブックシートは 1024 px です。
