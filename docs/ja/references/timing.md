# 強度、ボリューム、退場のリズム

先にキーフレームを書き、それから delay と life を埋めます。明るさとボリュームは 2 本の別々のカーブとして記述します：
明るさは解放の瞬間に跳ね上がりますが、爆発の炎や煙のボリュームのピークはもっと後かもしれません。シールドは安定した輪郭を保ち、
効果切れの時にだけ崩れます。レビューのピクセル `energy` は面積と明度を混ぜたもので、どちらのカーブとも一致しません。

## どのフェーズにも後継がある

| フェーズ | 答えるべき問い | よくある失敗 |
|---|---|---|
| 予備動作 | 見る人は、どこで・いつ何かが起こるか分かるか？ | 大きすぎて最終的な爆発に見える。着弾ストリップが先行する飛翔体で汚れている |
| 接触または解放 | この瞬間は前後のフレームより明確か？ | 大きな白い塊が残り続ける。接触が Lab のフィードバックとずれている |
| 本体 | フラッシュが消えた後も、アクションと属性が読み取れるか？ | 本体が早く消えて火花だけが残る。最初から最後まで変わらない一つの輪郭 |
| 二次モーション | 破片、煙、火花に原因と方向があるか？ | 装飾的なノイズのように、あらゆる方向へ一斉に撒き散らされる |
| 消散 | 残っているものはまだ変化しているか、時間どおりに終わるか？ | 空のテール。静止した汚い残像。`duration` の時点でまだ大きな本体が見えている |

本体と二次モーションは重なっていて構いません。5 つの区間を機械的に分ける必要はありません。ずらすのは読み取りのポイントです：
フラッシュが最初に去り、形が引き継ぎ、破片は動き続け、煙は最後に薄れます。後のレイヤーのほうが明るい場合は、
二撃目、リターンストローク、シールドの破壊などとして説明できなければなりません。

## 同梱サンプルの参考タイミング

サンプルのレシピから求めた絶対フレーム範囲です（最初の発生から最後のインスタンスの最大ライフまで。飛翔体は `flight` で解放）。
見える時間は画像で決まります。これらはすべてのエフェクトに使える定数ではありません。

「誰が誰から引き継ぐか」を借りる前に、用途と形を合わせます。頻繁に出る軽いヒットに爆発の長い煙のテールを与えてはいけませんし、
チャージを最初のフレームから暗くなるだけのものにしてもいけません。

## カーブは実フレームに着地させる

レシピの delay と life は 60 FPS のフレーム数、F カーブのキーはライフに対するパーセントです。delay d で生まれ、ライフ L が固定のレイヤーでは、
実フレーム t での変化はキー `100 × (t − d) / L` に置きます。ライフがランダムだと、インスタンスごとに変化する絶対時刻が異なります。
接触に合わせるには、ライフ固定のキーレイヤーを使います。

子の delay は親インスタンスの誕生から数えます。繰り返し生まれる親は、子ごとに独自の時計を与えます。`vfx brief-validate` が展開する、
最も早い誕生と最も遅い誕生を読んでください。「このレイヤーは 20 フレーム生きる」は、フレーム 20 で消えるという意味ではありません —
最後に生まれたインスタンスはまだ生きています。

飛翔体は `flight` で放出を止め、トレイルは各インスタンスのライフで終わります。煙のテールを延ばすには、フリップブックの区間を長くし、
色の減衰と適切なライフを組み合わせ、`duration` と同時生存インスタンスの予算を確認し直します。`duration` を上げるだけでは空のテールができ、
ライフを上げるだけでは連番が早く再生し終わってしまうことがあります。

## 最後のフレームに賭けない

ブリーフには退場の開始、退場の中間、消える時刻を記し、レビューでは少なくともその 3 つに加えて `duration` 後のチェック用フレームを
サンプリングします。長いエフェクトでは、ピークがサムネイルを占領してテールに空のタイルが一枚だけ、とならないよう、
80 % と 90 % のキーフレームを明示的に追加しても構いません。

シェル、柱、リングに目に見える崩れが出ない場合は、まずレンダラーがその組み合わせをサポートしているか確認し、
次に実際のジオメトリの断片、分割した弧、形状間の時間指定の受け渡しを検討します。コンパイルの読み戻しが正しくても、
「ディゾルブが効いている」ことにはなりません — [シールドのケース](cases.md#シールド隙間が一度も見えない崩れ) を参照してください。

各ラウンドでは、まず接触・本体の引き継ぎ・退場のどれを直すかを決め、そのレイヤーだけを変えます。順序と画面占有率は標準ストリップで、
侵食とトレイルは詳細シートで、リズムは Lab の等速再生で判断します。
