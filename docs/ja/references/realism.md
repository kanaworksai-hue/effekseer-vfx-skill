# 写真調の爆発、炎、煙

ブリーフがスタイライズされた既定の見た目ではなく、リアルな見た目（映画、実写のリファレンス、フォトリアルなゲーム）を求めるときに使います。
クラフトルール — 時間構造、明度の階層、形の変化 — はそのまま適用されますが、色、明るさ、テクスチャは写真から取ります。

## 写真から取る色と明るさ

燃料や弾薬の爆発を撮った昼間の写真とハイスピード映像は、次の値で一致します（sRGB、Lab のブルーム適用前）。
これらは `VFX_Kaiju_Explosion` のパレットです：

| 役割 | RGB | 補足 |
|---|---|---|
| 接触のコア | 255, 244, 214 | 淡い黄白色で、純白 **ではない**。短いスパイク一回で、Lab のフレームで約 8 までに消える |
| 炎の本体 | 255, 168, 72 | オレンジ。接触の後は本体が最も明るい部分 |
| 冷めていく縁 | 214, 84, 28 | 炎が煤と接するところの深い赤橙 |
| 最後の残光 | 120, 40, 18 → 60, 20, 10 | 煙の内側にくすんだ赤い溜まりが残り、やがて消える |
| 煤 | 38, 32, 29 | 暖かみのある黒に近い色で不透明：炎はその手前で燃える |
| 煙の柱 | 92, 84, 78 | 茶色がかった灰色。日の当たる上部は明るく、下側は暗い |
| 土埃のスカート | 150, 136, 118 | 地面の色で、煙より明るい |
| 蒸気 | 205, 215, 225 | ほぼ白で薄く、速く昇って消える |

- **炎にピンクやマゼンタを使わない。** 彩度の高い赤ピンク（R と B が高い）は、ひと目でゲームのエフェクトに見えます。
- **炎が白いのは長くない。** 写真では白熱したフレームは 1〜2 フレームで、その後最も明るいピクセルは黄橙色です。Lab のブルームの下では、
  長いライフの 10 % にわたって白に近いままのランプは白飛びしたフラッシュに見えます（独立レビューがまさにそれを指摘しました）。
  約 5 % からオレンジにします。
- **煙は炎よりずっと長く残り**、ゆっくり動きます：実際の爆発では火球は 1 秒ほどで消え、柱はその後何秒も昇り続けます。
  密度を保ち（colour_end のアルファを 0 より上に）、煙が消えてしまった後ではなく、まだ目に見えて薄れつつあるうちにエフェクトを終えます。
- **煙は上から照らされる。** 写真調の煙のシートは上部が明るく下側が暗いので、ロールは小さく（±12°）して光が上に留まるようにし、
  `spawn rotate=False` で放出して `velocity` がワールドの上向きになるようにします。
- エミッシブ：加算の炎には 1.3〜1.8 で十分です。それより明るい値は本体をブルームのしきい値の上に押し上げ、白くなってしまいます。
  説得力を生むのは明度の構造（淡いコア、オレンジの本体、暗い煤）であって、生の強度ではありません。

## テクスチャ

ペイント系のスタイライズされたひと吹きは、フォトリアルな世界の中ではカートゥーンに見えます。このスキルは写真調のフリップブックを 3 枚同梱しています
（4×4、1024²、画像モデルで生成して処理済み。プロンプトは `assets/examples/texture_prompts.json`）：

| テクスチャ | 用途 | ブレンド |
|---|---|---|
| `T_FireballSheet01` | 火球：アルファ = 輝度なので、熱い溜まりが光り、煤は透明になる | Add、`ramp` 付き |
| `T_FireballSootSheet01` | 同じ火球の不透明な本体（陰影のある灰色、シルエット全体） | Blend、炎より **前に** リストする |
| `T_SmokeSheet02` | 上部が照らされた、写真調の転がる煙の柱 | Blend、煙の色で色付け |

`smoke()` はどの `T_*Sheet*` テクスチャも 4×4 のフリップブックとして再生します。最後まで濃いままでなければならない柱には、フリップブックを遅くして
（`flipbook=dict(x=4, y=4, frame_length=8, loop='Once')`）、シートの最後のほぼ空のセルに届く前に止まるようにします。

## 地面と接する煙と炎

床や水面を貫くスプライトは、硬い水平の線を残します。地面の煙、土埃、蒸気には `soft` の距離（ワールド単位で、ひと吹きのサイズの
3 分の 1 から半分）を与えます — Forward+ で検証済みです。[エンジン規約](engine-conventions.md#レンダリングhdrlab) を参照してください。

## 写真調の爆発のレイヤー計画

奥から手前へ：陽炎 → 煙の柱（soft、遅いフリップブック）→ 煤の本体（Blend）→ 火球（Add、写真調の
ランプ）→ そこから投げ出される炎の塊 → 接触のフラッシュと短いブルーム → 柔らかい土埃のスカートが転がり出る地面のピボット →
地面の衝撃リングと屈折 → 火花の段 → 着地する暗い破片。`vfx examples show VFX_Kaiju_Explosion` で
タイムラインを表示できます。
