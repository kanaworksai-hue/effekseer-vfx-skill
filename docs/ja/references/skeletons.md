# カテゴリ別の骨格

骨格はレイヤーの役割とタイミングの関係を示すもので、ゲームのスタイルに合わせて削ってください。メインの形を一つ選び、
それに必要な補助レイヤーだけを加えます。軽いヒットはごく単純で構いませんし、フィニッシュ技には複数の段階があってもよい。
以下のすべてのカテゴリに、独立レビュー済みの完全なサンプルがあります（`vfx examples show <name>` は絶対フレームと役割付きの
レイヤー計画を出力し、`vfx examples add <name>` はそれをプロジェクトにコピーします）：`hit`、`slash`、`charge`、`shield`、`heal`、
および飛翔体 + 着弾のペア `fire`、`ice`、`poison`、`dark`。

## ヒット

参考：サンプル `hit`（`VFX_Hit_Heavy`）。接触点に集中した短い予備動作、短いフラッシュとギザギザのバーストが先に来て、その後に方向のある集中線と段階的な火花、
最後に土埃か少しの煙で終わります。白いフラッシュが接触を感じさせ、本体が力を伝えます。すべてのヒットに大きなリングと黒い煙が必要なわけではありません。

| 役割 | プリミティブ | 代替案 |
|---|---|---|
| 予備動作 | 縮んでいく `glow` | 内向きの線を数本 |
| 接触 | `flash` | 輪郭のある短く熱い形 |
| 本体 | `POP` + `DISSOLVE` のペイント系バースト `sprite`、`tilted_ring(..., tilt=(0,58,0))` | `shell` の空気の泡 |
| 二次モーション | `spark_burst`（2〜3 段階、噴射方向は一つ） | `spray` 付きの `radial_sparks` |
| 退場 | `smoke` の土埃、`motes` の残り火 | 素早く落ちる土埃。一回のヒットに数秒かけない |

ピーク後に細い針しか残らないなら、本体を長くするか強くします。花火のように見えるなら、パーティクルを足す前に放出方向と `travel` の方向を絞ります。予算 ≤ 60。

## 斬撃

参考：サンプル `slash`（`VFX_Slash_Fire`）。`swing()` のピボットが傾いた振りの平面を定義し、弧が空間を切り裂く楕円に見えるよう
約 ±30–40° ヨーを付けます。`slash_set()` はその中に残像、本体、熱い縁を置き（`slash_arc` を 3 つの幅で：2 フレーム遅れる幅広で薄暗い残像、
高彩度の本体、細く白い縁）、刃の後ろに屈折の弧を、さらに数フレーム保持するペイント系のセル調の三日月を加えます。三日月は
`billboard='Fixed'` で刃自身の平面（同じ lean）にあり、テクスチャの計測した膨らみ（`SLASH02_BULGE`）だけ回転しているので、
カメラの方を向くのではなく振りと一緒に傾きます。火花は弧に沿って時間差で出します。炎は剥がれる炎と立ち昇る残り火で、物理は短い金属の火花で、
氷は溜めと砕けで退場します。属性を変えると、色だけでなくモーションとマテリアルが変わります。

レイヤー間に弧の余白を保ちます。ターゲットの胸は配置のアンカーにすぎません：弧の見た目の中点は、テクスチャの膨らみ、回転、ピボットにも
左右されます — `vfx texture-info` で計測してください。テールがまだ三日月全体のままなら、煙の残像を足す前にスイープと侵食を直します。

## 爆発

参考：サンプル `VFX_Fire_Explosion`。Gather と Inward fuse がターゲットで引き締まり、短い Detonation flash が解放し、
Fireball と立ち昇る Mushroom が引き継ぎ、方向のある破片と火花が衝撃を運び、Smoke billow、土埃、地面の痕跡が重みを与えます。

炎はフラッシュの後も高彩度のボリュームを保たなければなりません — 広がるリングや小さな明るい点の集まりだけではいけません。
二次モーションは射線、地面、上方向に沿って組み立て、すべてのレイヤーが同じ球状の動きをしないようにします。
煙は炎の奥に描かれ、冷めた形を引き継ぎます。煙が中心を覆っているなら、まず順序と密度を確認します。地面の痕跡はどこに落ちたかを、
立ち昇るボリュームは噴き出したことを伝えます。全画面のグローを大きくしても、そのどちらの代わりにもなりません。
ピークだけでなく、引き継ぎは f18–42、煙は f54–66 を見てください。

## 飛翔体

参考：ペア `fire`、`ice`、`poison`、`dark`（`VFX_Projectile_Fire`、`VFX_Projectile_Ice`、
`VFX_Projectile_Poison`、`VFX_Projectile_Dark`）。ヘッドレイヤー（Fireball、
Hot core）はハンドルに追従し、Comet tail がヘッドに方向を与えます。Flame trail、Smoke trail、Embers は
`inherit=TRAIL` を使い、経路上に留まります。幅広のテール、細く熱い線、短く振りまかれるパーティクルにはそれぞれ異なるライフが必要で、
ヘッドと経路の両方が読み取れなければなりません。

発射、飛行中、到達、到達後、消去を確認します。飛行時間が固定なら、トレイルの密度は放出間隔とパーティクルのライフの組み合わせで決まります。
ヘッドの継承を変えると空間的な関係が変わります — トレイルを延ばして硬いチューブを隠してはいけません。着弾は対のエフェクトです：
飛翔体のストリップと着弾のストリップは別々にレビューし、やり取り全体は Lab で確認します。予算 ≤ 100。

## チャージと解放

参考：サンプル `charge`（`VFX_Magic_Charge`）：約 1 秒の内向きの溜め（f0–64）、一度の解放 f64–70、解放の火花は約 f86 まで。
負の `travel` を持つ `motes` と `radial_sparks` が内側へ集まり、傾きの異なる平面上の `orbit_band` リング 2 本がボリュームを作り、
コアとオーラが蓄積し、解放フラッシュ、`shell`、火花が一度のはっきりした解放を与えます。カメラとステージのフィードバックで解放を強めても構いませんが、
集まる過程そのものが読み取れなければなりません。

内部に流れがなく Z 回転するだけのリングは、回転するアイコンになってしまいます。UV フロー（`alpha_scroll`）、傾いた平面、
内向きの移動を使います。解放が巨大で予備動作が弱いなら、すべての明るさを上げるのではなく、まず見える集束の経路を作ります。

## シールドと持続する状態

参考：サンプル `shield`（`VFX_Shield_Dome`）と [cases](cases.md) のシールドのケース。短い展開時のきらめき、持続するボリュームのための `mesh` 球体の `shell` とリム、保持中を生かす表面の流れ、スキャンバンド、きらめき。
最後にはシェル全体が、実際の隙間を持つ `shell_fragments` に引き継がれ、破片の動きと色の減衰が退場を作ります。

安定とは、毎フレーム点滅することでも、完全な球が一度に消えることでもありません。まずシェルの内側でキャラクターが読み取れるかを確認し、
次に表面の流れと退場を確認します。ここでは 6 枚の球体破片が検証済みの解決策です。他のマテリアルが本当にディゾルブできるかは、別途テストする必要があります。

## ヒールとバフ

参考：サンプル `heal`（`VFX_Heal`）。地面の `decal` の紋章が所有者を示し、`column` がゆっくり昇るボリュームを作り、昇るリング、シンボル、生命の `motes` が意味を運び、
グローときらめきで締めくくります。ヒールを、激しい白いフラッシュと飛び散る破片を持つ攻撃にしてはいけません。柔らかくても脈打ってもよいですが、
輪郭を保ち、標準カメラで見え続けなければなりません。白いピークはこのカテゴリの合格基準ではありません。評価基準の用途による例外を使います。

## サンプルコードの使い方

`vfx examples show <name|ID>` は、絶対フレームと役割付きの完全なレイヤー計画を出力します。`vfx examples add <name>` は、
ソース、ブリーフ、ペイント系テクスチャをプロジェクトにコピーします。サンプルをベースラインとして残しておきたい場合は、
その場で編集するのではなく、新しい ID でコピーを作って改造します。サンプルの過去のスコアはスキル自身のレンダーについてのもので、
あなたのビルドについてではありません：変更したら、ビルド、レビュー、独立した採点をやり直してください。2 つのサンプルは `iterate` と判定されました
（`vfx examples` の `historical_review.worst` を参照）。それでもそれぞれのパターンを教えてくれ、その最も弱い点は最初の練習課題に向いています。
