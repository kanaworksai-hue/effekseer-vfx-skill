# 明度、色、レイヤーの組み合わせ

標準カメラで見る人が読み取れるものを 3 つ計画します：短く明るい点、形を持つ本体、そして本体を引き立てる暗い側面または素材。
レイヤーを足すたびに、それが直す目に見える問題を言えなければなりません。レイヤー数は品質の尺度ではありません。

## まずパレットの役割

| 役割 | 見えるべきもの | 最初の調整 |
|---|---|---|
| core | 小さな最も熱い領域、または細く熱い縁。接触時にはっきり見える | エミッシブを足す前に、サイズと持続時間を制御する |
| body | 属性とアクションを伝える高彩度の輪郭 | 白いフラッシュが去った後も形を保つ。消すのではなく色を冷ます |
| dark | 裏打ち、凹み、亀裂、または本物の影 | Blend を使い、明るい背景と暗い背景の両方で確認する。黒の Add ではこの役目は果たせない |
| matter | 煙、土埃、破片、滴 — 重み | 彩度を下げ、内部の明度と見える退場を保つ |
| accent | 小さな第二色の手がかり | 一つの場所かフェーズに限定し、メインカラーを奪っていないか確認する |

メインカラーは単色でも、近い色の系統でも構いません。第二色には仕事が必要です（氷のプリズムの縁取り、毒の暗いコア）。
レイヤーごとに色を選んではいけませんし、補色は必須ではありません。炎の隣の煙が灰色になる前に暖色を経由するのは構いませんが、
煙を全部高彩度のオレンジで塗り直してはいけません。

色相より先に、グレースケールで明度を読みます。コア、本体、背景がすべて白に近いなら、オレンジのパーティクルを足しても構造は戻りません。
どのレイヤーが最初に画を白く飛ばしているのかを突き止めます：接触、グロー、本体、あるいは重なった複数の Add レイヤー。

## 3 種類のコピーはそれぞれ別の仕事をする

| 技法 | ジオメトリとタイミング | 目的 | よくある間違い |
|---|---|---|---|
| 暗い裏打ち（`shadow()`） | 独自の形で、やや大きくてもよい。本体とほぼ同じフェーズ | 明るい色を引き立てる。明るい背景での可読性 | 黒い塊が本体を飲み込む（ブラックホールに見える）。暗いステージでは見えない |
| 明暗ペア（`contrast_pair()`） | 同一の輪郭、固定の角度、同じ動きと発生時刻 | 一つの形の内部に明暗の構造を加える | ランダムな 2 つの輪郭がずれていき、無関係な 2 本のストロークになる |
| 煙の残像（`decay()`） | 遅らせても、遅く・長くしてもよく、色とブレンドも変えられる | 光が消えた後に物質を残す | 暗い刃の弧が長く漂い、汚れた擦れ跡に見える |

`decay()` はジオメトリが同一の明暗ペアではありません。

決定的なペアでは、`count=1`、life、size、rotation、position、spin、travel、フリップブックの開始フレームを固定します。
別々のパーティクルノードはそれぞれ独自に乱数を引くため、範囲を揃えてグローバルシードを一つにしても、同じ角度には **なりません**。
多くの方向が必要な場合は、外側のレイヤーで一つの固定角度を選び、両方のノードにその固定値を使います。各レイヤーに個別の `[0,360]` を与えてはいけません。

正確なペアでは、同じ life と正規化したカーブを保ちます。life を延ばすと、ライフの 50 % に達する実フレームも動くので、
スケールとスイープがずれていきます。暗いレイヤーを後で退場させたいなら、カーブを明示的に計算し直すか、独立した残像にして、
輪郭が一致したペアとは呼ばないようにします。

ここで実測済み：後のレイヤーが手前に描かれ、Model の ZWrite ではこの遮蔽は得られません — 描画順を使います。Add の明るい本体より前に
描かれる Blend の暗いコピーは出発点にすぎません。手前の暗い切り込みと奥の暗い裏打ちは別のデザインなので、レンダーを見て決めます。

```python
from vfxkit.primitives import *

body = sprite('Matched burst', 'T_Explosion01', (255, 120, 30, 255),
    life=16, delay=3, size=2.0, rotation=[0, 0, 30],
    size_curve=[[0, .8], [30, 1], [100, 1.1]],
    color_curve=ramp((0, (255, 120, 30, 255)), (100, (180, 35, 10, 0)))['color_curve'],
    alpha_texture='T_NoiseTile01', cutoff=[[0, 0], [100, .8]],
    fade_in=0, fade_out=4, emissive=1.2)
layers = contrast_pair(body)   # [Blend dark underlay, the bright body]; splice into effect(..., [*layers, ...])
```

`contrast_pair(body)` は [Blend の暗い下敷き, 明るい本体] を返すので、`effect(..., [*layers, ...])` に展開して使います。
2 つのレイヤーはジオメトリと時計を共有し、色とマテリアルが異なります。それでもアルファ、ブレンド、カットオフは実際の縁を変えるので、
レンダーで確認してください。ピクセル単位で完全に重なることは保証されません。30° はデモ用の角度で、このテクスチャの向きではありません：
`vfx texture-info` を実行し、アクションの方向には実測した角度を使います。このヘルパーが扱うのは Sprite 一つだけです。
Ring と Model のペアは明示的に設計します。

## サイズとライフの出発点

スプライトカードのサイズではなく、本体の **見える幅 B** と **ライフ L** を基準に測ります：細い線が一本だけのテクスチャは、
同じサイズの塗りつぶされたカードと同じ重さにはなりません。

| レイヤー | 出発点 | 確認方法 |
|---|---|---|
| 熱いコア | 幅は約 0.2–0.5 B、または本体の細い縁一本 | ピークでコアが見つかり、その後も本体が見つかる |
| 暗いペア | 本体と同じサイズとライフ | サイズを変えたら、切り込みか裏打ちかを決め直す |
| 独立した裏打ち | やや大きく、約 1.1–1.4 B | 本体の外側にくっきりした黒い円ができない |
| 薄暗い残像 | 約 1.1–1.2 L | 明るいレイヤーが消えた後、短く意図的なレイヤーが残る |
| 煙の残像 | `decay()` が与える長めのライフ | 退場中も変形し続ける。静止した暗い弧ではない |

これらは調整の出発点であって、統計でも lint ルールでもありません。斬撃や持続する柱は長く細い熱い縁を使って構いません。
ヒールやシールドには攻撃のような白いフラッシュは不要です。比率よりも、カーブの一致、余白、標準カメラのほうが重要です。

## 白い塊と黒い塊の修正順序

本体が白で埋まる場合：原因を特定するため、グロー、接触、重複した Add レイヤーを一つずつオフにします。次に接触を短くし、
次に本体の長い高輝度区間を削り、暗色は最後に足します。テクスチャ、カーブ、煙、カメラシェイクを同時に変えてはいけません —
何が効いたのか分からなくなります。

暗いレイヤーが別の黒いストロークに見える場合：まず角度とサイズの位置合わせを確認し、次に発生時刻とライフ、その後でようやくグレーの明度です。
間違ったジオメトリを不透明度を下げてごまかしてはいけません。明るい背景では機能するのに既定のステージで機能しない場合は、
dark と matter の役割を区別したまま、素材レイヤーに適切なグレーか局所的に照らされた色を与えます。

完了したラウンドは、見たフレームを挙げて改善点を一文で言えるはずです。例：「f12 以降、白いフラッシュは消え、オレンジレッドの火球が輪郭を保っている」。
