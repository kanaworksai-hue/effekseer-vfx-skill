# リファレンスクリップとの比較

`ffmpeg` と `ffprobe` が必要です。ユーザーが提供したクリップ、または使用を許可されたクリップだけを使い、出所を記録します。

1. `vfx reference-import <clip.mp4> --start 0 --end 2 --slow 2 [--roi x y w h] [--source-url <url>]` は、最大
   30 秒分のメディアを、バージョン管理から除外された `vfx/work/references/` にデコードします。`--slow 2` はクリップが半分の速度で再生されることを意味するので、
   エフェクトの時間 = `--start` を基準としたクリップの時間 ÷ 2 です。返された `overview` 画像を開きます。リファレンス ID と時刻を
   ブリーフの `reference` フィールドに入れます。
2. ラベル付きのフレームを順に読み、予備動作、接触、本体、二次モーション、退場をブリーフの beats に書きます。詳細を見るには、
   クリップ全体を読み込み直すのではなく、短い区間一つに対して `vfx reference-frames <reference_id> <start> <end> --count 8` を使います。
   クリップの速度が不明で、リズムがそれに依存する場合は質問します。
3. レビュー後、`vfx reference-compare <reference_id> <evidence_id> --times 0.1 0.3` で、リファレンスの瞬間と
   撮影済みの Godot フレームを正確に対にします（足りないものは `vfx review --key-frames` で撮影）。リズム、輪郭、
   画面占有率、高彩度の本体、暗いレイヤー、残滓を比較します。各ビューは独自のアスペクト比と時刻ラベルを保ちます。明示しないクロップやスケールで
   「同じサイズ」に揃えてはいけません。

この分析は近似です：圧縮、背景、ブルームはピクセルを変え、カメラの動きやカットは変化した面積を汚染します。カメラが動く場合は、
手動のキーフレームと明示的な ROI を使います。動画からワールドのサイズ、エミッシブの値、パーティクル数、見えないテクスチャを推測してはいけません。
近似はブリーフに明記します。リファレンスからの観察は形とリズムの指針であり、このエンジンで実測した単位、UV、HDR、継承のルールより優先されることはありません。
